# 징비 — 일곱 해의 패

임진왜란(1592–1598) 일곱 해를 일곱 막으로 건너는 덱빌딩 로그라이크입니다.
이순신이나 권율이 되어 카드를 모으고, 거리를 재며 싸우고, 임금의 의심을 견딥니다.

## 바로 하기

`jingbi.html` 하나만 브라우저로 열면 됩니다. 설치도, 인터넷 연결도 필요 없습니다.
그림·소리·데이터가 모두 이 파일 안에 들어 있습니다. 게임은 브라우저에 저장되어 ‘이어하기’로 돌아올 수 있습니다.

| 조작 | 키보드·마우스 | 터치 |
|---|---|---|
| 카드 내기 | 카드를 누르고 대상(적)을 누른다, 또는 1~0 | 한 번 눌러 고르고, 한 번 더 눌러 낸다 |
| 설명 보기 | 카드·적·아이콘 위에 마우스 | 길게 누른다 |
| 턴 종료 | Space | ‘턴 종료’ 단추 |
| 덱 보기 | D | 오른쪽 위 ‘덱’ 단추 |
| 글 넘기기 | Enter 또는 Space (처음 누르면 글이 다 나오고, 한 번 더 누르면 넘어간다) | 화면을 누른다 |
| 사건 선택지 | 1 2 3 | 선택지 단추 |
| 저장하고 나가기 | S (지도에서) | ‘저장하고 나가기’ 단추 |
| 소리 켜고 끄기 | M | 설정 |

## 놀이 방법

- **거리.** 싸움은 원거리·중거리·근접 세 칸에서 벌어집니다. 사격은 원거리에서 ×1.5, 근접에서 ×0.5입니다. 백병은 근접에서 ×1.2입니다. 왜군은 다가오고, 밀어내기 카드로 떼어 놓습니다.
- **군령·진형.** 한 턴에 군령 3으로 카드를 냅니다. 진형은 적 턴의 피해를 먼저 막고 적 턴이 끝나면 사라집니다.
- **적의 의도.** 적 머리 위에 다음 턴에 할 일이 그림과 숫자로 나옵니다. 조총병은 ‘장전’한 다음 턴에 ‘조총 사격’을 하고, ‘관통’ 공격은 진형을 무시합니다.
- **군량.** 시장의 돈이자 일부 카드의 값입니다. 명군 카드는 군량을 먹습니다.
- **임금의 의심.** 0~10입니다. 4·7·10을 처음 넘을 때 어명 카드가 덱에 섞입니다. 10이면 부장 하나가 옥에 갇힙니다. 4막 어전회의에서 의심이 7 이상이면 파직됩니다. 장계를 올리면 내려갑니다.
- **부장.** 부장 둘을 데리고 다닙니다. 늘 켜진 능력을 주고, 쓰러질 위기에 한 번 대신 섭니다.
- **장계.** 결전에서 이기면 공을 주장·전하·명군에게 나눕니다. 주장에게 주면 카드가 강해지고 의심이 오릅니다.
- **지도.** 전투·정예·사건·군영·시장·조정·결전 마디를 골라 나아갑니다. 2막은 바닷길(수군)과 뭍길(의병)로 갈립니다.
  - **군영:** 휴식(병력 회복) · 훈련(카드 한 장 강화) · 농사(군량).
  - **시장:** 카드와 기물을 사고, 한 번은 군량을 내고 카드 버리기를 할 수 있습니다.
  - **조정:** 장계 올리기(의심을 낮춘다) · 장수 영입 · 명군 요청(3막부터).
- **결말.** 실록·징비·난세 세 가지입니다. 무엇을 지키고 무엇을 잃었는지가 결말을 가릅니다.

## 개발

개발할 때는 `index.html`이 `src/` 아래 파일을 순서대로 불러옵니다. 모든 그림은 Canvas 2D로 그리고, 외부 라이브러리와 그림 파일은 없습니다.

| 파일 | 전역 | 하는 일 |
|---|---|---|
| `src/00_core.js` | `Core` | 균형 수치(BAL), 시드 난수, 이벤트 버스, 저장 |
| `src/01_text.js` | `TXT` | 모든 한국어 문구, 날짜(`1592년 4월 15일`), 효과 설명, 조사(`TXT.josa`) |
| `src/02_cards.js` | `CARDS` | 카드 99장 |
| `src/03_enemies.js` | `ENEMIES` | 적과 편성, 결전 7 |
| `src/04_generals.js` | `GENERALS` | 주장·부장·기물 |
| `src/05_events.js` | `EVENTS` | 사건 29 |
| `src/06_map.js` | `MAPDATA` | 일곱 막의 지도 |
| `src/07_combat.js` | `Combat` | 전투 규칙(순수 함수) |
| `src/08_run.js` | `Run` | 게임 진행과 화면 요청 |
| `src/09_input.js` | `Input` | 마우스·터치·키보드 |
| `src/10_audio.js` | `Audio_` | WebAudio 효과음과 음악 |
| `src/10b_art.js` | `ART` | 캐릭터(이순신·권율·부장·임금·관리·상인·왜군)·배·성·아이콘·카드 그림·일월오봉도 |
| `src/11_ui_battle.js` | `UIBattle` | 전투 화면과 공통 그리기 도구(`UIBattle.gfx`: 단청 판·단추·글자 정리) |
| `src/12_ui_screens.js` | `UIScreens` | 제목·지도·사건·시장·군영·조정·어전회의·보상·결말 등 나머지 화면 |
| `src/13_main.js` | `Main` | 장면 전환과 주 루프 |

`DESIGN.md`가 기획 정본이고, `CONTRACT.md`가 구현 계약입니다. 계약과 기획이 다른 곳은 `CONTRACT.md` 13절에 이유와 함께 적었습니다.

표기 규칙: 화면에 나오는 글에는 한자와 영어를 쓰지 않습니다. 대사는 “ ”, 카드·기물·제목은 ‘ ’로 묶고, 「」『』〔〕는 쓰지 않습니다. 규칙 문구에서는 ‘카드’, ‘턴’이라고 씁니다.

단일 파일 만들기:

```bash
py -3 build.py --out jingbi.html
```

검사:

```bash
node test/check.js
```

```bash
node test/headless.js --quiet --run test/ui_smoke.js --seed 31 --win
```

```bash
node test/headless.js --quiet --run test/sim.js --seeds 1-150 --leader both --bot greedy --json
```

```bash
py -3 test/shots.py --out <폴더> [장면 이름 ...]
```

- `test/check.js`는 로드 순서, 전역 하나 규칙, 각 모듈 자가 검사, 결정성, 글자 위생(한자·「」·영어 꼬리표·`이(가)` 꼴·턴을 뜻하는 ‘합’), 빌드본이 최신인지를 봅니다.
- `test/ui_smoke.js`는 가짜 캔버스에서 모든 화면과 전투를 그려 보고 오류를 셉니다. `--leader gwon`으로 권율도 볼 수 있습니다.
- `test/sim.js`는 봇으로 게임을 돌려 균형 보고서를 냅니다. 시드 150개에 주장 둘이면 300판이고, 마지막 보고서는 `test/last_sim.json`에 있습니다.
- `test/shots.py`는 헤드리스 Edge(없으면 Chrome)로 `test/shots.json`의 장면을 1280×720 PNG로 찍습니다. 서버 없이 `file://`로 열고, 장면에서 오류가 나면 `FAIL`을 찍습니다. 장면 이름을 주면 그것만 찍습니다.
- `test/shot.html`은 화면 확인용입니다. 주소 뒤 `#` 다음에 준비 코드를 넣으면 그 장면을 띄웁니다. 전투 승패 화면은 `Main.debug.winBattleHold()` / `loseBattleHold()`로 멈춰 둘 수 있습니다.

## 알려진 빈틈

- 싸움의 61%가 근접에서 끝납니다. 원거리를 지키는 보상을 더 키울 여지가 있습니다.
- 봇은 어명 카드를 거의 쓰지 않습니다. 사람에게는 다를 수 있지만 확인이 필요합니다.
- 봇 게임에서는 파직과 칠천량 분기에 한 번도 닿지 않았습니다. 이 분기는 자가 검사와 화면 사진(`test/shots.json`)으로만 확인했습니다.
