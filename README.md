# 징비 — 일곱 해의 패

임진왜란(1592–1598) 일곱 해를 일곱 막으로 건너는 덱빌딩 로그라이크입니다.
이순신이나 권율이 되어 패를 모으고, 거리를 재며 싸우고, 임금의 의심을 견딥니다.

## 바로 하기

`jingbi.html` 하나만 브라우저로 열면 됩니다. 설치도, 인터넷 연결도 필요 없습니다.
그림·소리·데이터가 모두 이 파일 안에 들어 있습니다. 판은 브라우저에 저장되어 「이어하기」로 돌아올 수 있습니다.

| 조작 | 키보드·마우스 | 터치 |
|---|---|---|
| 카드 내기 | 카드를 누르고 대상(적)을 누른다, 또는 1~0 | 한 번 눌러 고르고, 한 번 더 눌러 낸다 |
| 설명 보기 | 카드·적·아이콘 위에 마우스 | 길게 누른다 |
| 턴 마침 | Space | 「턴 마침」 단추 |
| 내 패 보기 | D | 오른쪽 위 「패」 단추 |
| 저장하고 나가기 | S (지도에서) | 「저장·나가기」 |
| 소리 켜고 끄기 | M | 설정 |

## 놀이 방법

- **거리.** 싸움은 원거리·중거리·근접 세 칸에서 벌어집니다. 사격은 원거리에서 ×1.5, 근접에서 ×0.5입니다. 백병은 근접에서 ×1.2입니다. 왜군은 다가오고, 「밀어내기」 패로 떼어 놓습니다.
- **군령·진형.** 한 턴에 군령 3으로 패를 냅니다. 진형은 적 턴의 피해를 먼저 막고 적 턴이 끝나면 사라집니다.
- **군량.** 장시의 돈이자 일부 패의 값입니다. 명군 패는 군량을 먹습니다.
- **임금의 의심.** 0~10입니다. 4·7·10을 처음 넘을 때 어명 패가 덱에 섞입니다. 10이면 부장 하나가 옥에 갇힙니다. 4막 어전회의에서 의심이 7 이상이면 파직됩니다. 장계를 올리면 내려갑니다.
- **부장.** 부장 둘을 데리고 다닙니다. 패시브를 주고, 쓰러질 위기에 한 번 대신 섭니다.
- **장계.** 결전에서 이기면 공을 주장·임금·명군에게 나눕니다. 주장에게 주면 패가 강해지고 의심이 오릅니다.
- **지도.** 싸움·정예·사건·군영·장시·조정·결전 마디를 골라 나아갑니다. 2막은 바닷길과 뭍길로 갈립니다.
- **결말.** 실록·징비·난세 세 가지입니다. 무엇을 지키고 무엇을 잃었는지가 결말을 가릅니다.

## 개발

개발할 때는 `index.html`이 `src/` 아래 파일을 순서대로 불러옵니다. 모든 그림은 Canvas 2D로 그리고, 외부 라이브러리는 없습니다.

| 파일 | 전역 | 하는 일 |
|---|---|---|
| `src/00_core.js` | `Core` | 균형 수치(BAL), 시드 난수, 이벤트 버스, 저장 |
| `src/01_text.js` | `TXT` | 모든 한국어 문구, 날짜, 효과 설명 |
| `src/02_cards.js` | `CARDS` | 카드 99장 |
| `src/03_enemies.js` | `ENEMIES` | 적과 편성, 결전 7 |
| `src/04_generals.js` | `GENERALS` | 주장·부장·기물 |
| `src/05_events.js` | `EVENTS` | 사건 29 |
| `src/06_map.js` | `MAPDATA` | 일곱 막의 지도 |
| `src/07_combat.js` | `Combat` | 전투 규칙(순수 함수) |
| `src/08_run.js` | `Run` | 판 진행과 화면 요청 |
| `src/09_input.js` | `Input` | 마우스·터치·키보드 |
| `src/10_audio.js` | `Audio_` | WebAudio 효과음과 음악 |
| `src/10b_art.js` | `ART` | 캐릭터·배·성·아이콘·카드 그림 |
| `src/11_ui_battle.js` | `UIBattle` | 전투 화면과 공통 그리기 도구 |
| `src/12_ui_screens.js` | `UIScreens` | 제목·지도·사건·장시 등 나머지 화면 |
| `src/13_main.js` | `Main` | 장면 전환과 주 루프 |

`DESIGN.md`가 기획 정본이고, `CONTRACT.md`가 구현 계약입니다. 계약과 기획이 다른 곳은 `CONTRACT.md` 13절에 이유와 함께 적었습니다.

단일 파일 만들기:

```bash
py -3 build.py --out jingbi.html
```

검사:

```bash
node test/check.js
```

```bash
node test/headless.js --quiet --run test/ui_smoke.js --seed 31 --win
```

```bash
node test/headless.js --quiet --run test/sim.js --seeds 1-150 --leader both --bot greedy --json
```

- `test/check.js`는 로드 순서, 전역 하나 규칙, 각 모듈 자가 검사, 결정성을 봅니다.
- `test/ui_smoke.js`는 가짜 캔버스에서 모든 화면과 전투를 그려 보고 오류를 셉니다.
- `test/sim.js`는 봇으로 판을 돌려 균형 보고서를 냅니다. 시드 150개에 주장 둘이면 300판이고, 마지막 보고서는 `test/last_sim.json`에 있습니다.
- `test/shot.html`은 화면 확인용입니다. 주소 뒤 `#` 다음에 준비 코드를 넣으면 그 장면을 띄웁니다.

|---|---|

| 1막 사망 | 3.7% |
| 결말 | 난세 233 · 징비 47 · 실록 20 |
| 전투당 평균 턴 | 4~5턴 |
| 예외·교착·의도 불일치 | 0 |

## 알려진 빈틈

- 싸움의 61%가 근접에서 끝납니다. 원거리를 지키는 보상을 더 키울 여지가 있습니다.
- 봇은 어명 패를 거의 쓰지 않습니다. 사람에게는 다를 수 있지만 확인이 필요합니다.
- 봇 판에서는 파직과 칠천량 분기에 한 번도 닿지 않았습니다. 이 분기는 자가 검사로만 확인했습니다.
